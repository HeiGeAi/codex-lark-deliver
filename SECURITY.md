# Security Policy

## Supported Version

The latest commit on the default branch is supported. Older snapshots are not maintained.

## Reporting a Vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/HeiGeAi/codex-lark-deliver/security/advisories/new).

Do not include app secrets, access tokens, verification tokens, encryption keys, or user data in a public issue.
